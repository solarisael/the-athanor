# GUI Prototype Task Rule

Before inspecting, editing, or verifying any file in `gui-prototype/`, MUST read `LESSONS_MAP.md` in this directory. The repository-root lesson map is not a substitute: this map owns the prototype's interaction grammar, code format, taste, honesty boundary, and browser proof.

If the task proposes moving an accepted behavior into production, also read `../gui/LESSONS_MAP.md` and follow its prototype-to-production gate. Do not edit `gui/` merely because the prototype changed.
