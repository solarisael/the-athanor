# House for companions

A companion that forgets you every restart is not really a companion. House keeps important memories and shared history available as the relationship continues.

Your room carries that history across restarts, model changes, and provider changes. The room belongs to the operator, not to one model endpoint. House keeps separate layers for identity, current state, recent context, and deep memory, and retrieves the evidence relevant to the current turn while preserving where it came from.

Corrections move through supersession, so changed truths do not compete forever with the records they replaced. Memory and lesson stores hold memories, coding lessons, project lessons, writing lessons, and audio lessons.

The lifecycle tools are simple:

- `recall` retrieves older evidence.
- `remember` records durable events, decisions, or lessons.
- `sleep` leaves a compact handoff for the next session.
- `wake` catches the latest handoff.

There is no meaningful data ceiling. Full House adds PostgreSQL memory authority, durable database memory, typed stores, local semantic search, and larger archives.
